# Demo

Each clip shows one feature, recorded with the test build's sample accounts. `make demo` records them again.

## Unified list and sending

![Unified list, open a chat, send](demo/list-and-send.gif)

## Keyboard navigation

**Ctrl+J** moves between unread chats, **Alt+↑/↓** between all chats, and **i** / **Esc** switch between writing and scrolling.

![Keyboard navigation](demo/keyboard-nav.gif)

## Search

**Ctrl+K** searches every conversation and jumps straight to a message.

![Command palette search](demo/palette-search.gif)

## Photos, voice notes and GIFs

![Photo, voice note and GIF](demo/media.gif)

## Replies and reactions

![Reply and react](demo/reply-reaction.gif)

## Editing a message

**Esc** then **E** loads a sent message back into the composer; **Enter** saves the change.

![Edit a message](demo/editing.gif)

## Every action is a command

**Ctrl+/** opens the command palette on every action in the app, not just conversations; typing filters it the same way **Ctrl+K** filters chats.

![Command palette](demo/command-palette.gif)

## Send later

**Ctrl+L** queues the message instead of sending it now; the queued message's "Sends at …" row shows above the composer until it goes.

![Send a message later](demo/send-later.gif)

## Pinning

Pin a chat from the command palette, then **Ctrl+Shift+↑/↓** reorders the pinned chats at the top of the list.

![Pin and reorder chats](demo/pins.gif)

## What's new

The command palette's "What's new" command lists each release's changes in-app; **j**/**k** scroll between releases.

![What's new release notes](demo/whats-new.gif)
