# Using your own Telegram API keys

OmaMessenger signs in with its own Telegram API id and hash by default, so adding an account needs nothing from you beyond the sign-in itself.

To use an app of your own instead:

1. Register one at [my.telegram.org](https://my.telegram.org/apps) to get an API id and hash.
2. In the command palette, choose **Add a Telegram account with your own API keys**.
3. Enter the id and hash you registered, then sign in as usual.
